# NOROSHI BOT

Bot Discord berbasis Node.js yang dibuat dari nol untuk kebutuhan komunitas Roleplay, khususnya server SA-MP Roleplay.

Project ini dibuat agar developer lain bisa belajar, mengembangkan, dan menggunakan sistem yang sudah tersedia secara lebih mudah.

---

## Features

✅ User Control Panel Registration  
✅ Account Verification System  
✅ Reset Password via Discord DM  
✅ Modal Interaction System  
✅ MySQL Database Integration  
✅ SA-MP Server Query  
✅ Modular Command Handler  
✅ Button & Modal Components  
✅ Auto Restart Support

## Installation

Clone repository:

```bash
git clone https://github.com/ahmazuqi/noroshi-bot.git
cd noroshi-bot
```

Install dependencies:

```bash
npm install
```

Run bot:

```bash
node noroshi.js
```

Atau gunakan:

```bash
start.bat
```
